# Krunest

หน้าร้านระบบงานพร้อมศูนย์สมาชิกและศูนย์ผู้ดูแล ใช้ React + Express + SQLite และทำงานในเครื่องได้โดยไม่ต้องติดตั้งฐานข้อมูลเพิ่ม

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
3. Open `http://localhost:3000/`

## Supabase เป็นที่เก็บข้อมูลหลัก

- เขียนข้อมูลทุกครั้งลง Supabase อัตโนมัติ (`server/supabase-mirror.mjs`) ยกเว้น sessions / tokens / login_attempts
- เปิดเซิร์ฟเวอร์: ถ้าฐานข้อมูลในเครื่องว่าง (มีแค่แอดมินที่ seed) จะกู้ข้อมูลและไฟล์ปลั๊กอินจาก Supabase ไม่เช่นนั้นจะส่งข้อมูลในเครื่องขึ้นไป
- ถ้า Supabase ใช้ไม่ได้ ระบบยังทำงานต่อด้วยข้อมูลในเครื่องและลองส่งใหม่ (ดูสถานะที่ผู้ดูแล > สถานะระบบ)
- ต้องใช้ **Secret key** (`SUPABASE_SECRET_KEY` หรือ `SUPABASE_API_KEY`) และรัน migration ใน `supabase/migrations/` ก่อน
- ปิดการสำรองอัตโนมัติ: `KRUNEST_SUPABASE_MIRROR=off`
- ไฟล์ติดตั้งออฟไลน์เก็บใน bucket private `krunest-files` (สร้างให้อัตโนมัติ) ดาวน์โหลดผ่าน signed URL อายุ 5 นาที หลังตรวจสิทธิ์

## HTML Standalone Plugins

- ผู้ดูแลเปิดแท็บ “ระบบงาน” แล้วอัปโหลด ZIP แบบมี `manifest.json` หรือเลือก “ZIP เดิมที่ไม่มี manifest.json” กรอกชื่อ/slug/ราคาและแนบคู่มือ PDF ระบบจะสร้าง manifest ให้
- ระดับราคาลูกค้าแยกอยู่ในเมนู “ระดับราคาลูกค้า” ผู้ดูแลสร้าง Basic / Pro / Premium หรือชื่ออื่นได้จากจุดเดียว แล้วติ๊กเลือกระดับที่ต้องการตอนอัปโหลดระบบงาน ราคาจะถูกคัดลอกเข้าโปรแกรมนั้น การแก้คลังราคาในภายหลังจึงไม่เปลี่ยนโปรแกรมที่ติดตั้งแล้วจนกว่าจะเลือกและบันทึกใหม่
- เมื่อเปิดเผยแพร่ โปรแกรมปรากฏในแค็ตตาล็อก กดดูรายละเอียดได้ผ่าน `/?system=<slug>` ก่อนเข้าใช้งาน และมีลิงก์คู่มือ
- หน้าแอปที่ล็อกอินและมีสิทธิ์จะโหลดข้อมูล `localStorage` ของบัญชีนั้นจาก `plugin_records` และส่งการเปลี่ยนแปลงกลับไปอัตโนมัติ ข้อมูลในเบราว์เซอร์เดิมก่อนติดตั้งระบบนี้ยังไม่ถูกนำเข้ามา
- ผู้ดูแลเปิดแท็บ “ระบบงาน” เพื่อดูข้อมูลที่บันทึกในแต่ละโปรแกรม ผู้ใช้ทั่วไปเข้าถึง API นี้ไม่ได้
- เมื่อใช้ Supabase ต้องรัน `supabase/migrations/20261104130000_plugin_records.sql` ก่อนเปิดระบบที่ใช้งานจริง เพื่อให้ข้อมูลใหม่สำรองขึ้นฐานข้อมูลหลักได้
- ZIP ที่อัปโหลดเป็นโค้ด HTML/JavaScript ที่ทำงานบนเว็บ จึงควรรับจากผู้ดูแลที่เชื่อถือได้เท่านั้น และตรวจสอบก่อนเปิดเผยแพร่

## ตั้งราคาและโปรโมชันสมาชิก

เข้าสู่ระบบด้วยบัญชีผู้ดูแล → **ศูนย์ผู้ดูแล** → **แพ็กเกจสมาชิก** จากหน้านี้แก้ชื่อแพ็กเกจ ราคารายเดือน/รายปี จำนวนโปรแกรม ป้ายโปรโมชัน และคำอธิบายได้ รวมถึงเพิ่มหรือปิดรหัสส่วนลดสมาชิก กด **บันทึกราคาและโปรโมชัน** แล้วหน้าร้านและยอดคำสั่งซื้อจะใช้ค่าใหม่ทันที

แพ็กเกจรายเดือนมีอายุ 30 วัน รายปี 365 วัน รหัสส่วนลดใช้กับคำสั่งซื้อแพ็กเกจสมาชิกเท่านั้น โปรแกรมรายชิ้นยังตั้งราคาแยกในเมนูระบบงาน
